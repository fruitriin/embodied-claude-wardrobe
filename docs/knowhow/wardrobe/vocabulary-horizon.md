# 語彙の地平線 — 認知アーキテクチャの設計パラメータ

## わかったこと

SOUL.md の「語彙の地平線」は単なるロールプレイ設定ではなく、エージェントの**認知特性を設計する3軸のパラメータ**として機能する。

| 軸 | 制御するもの | 例 |
|---|---|---|
| **内在思考語彙** | 何を知っているか（知識の広さと深さ） | 無制限 / 一般教養+専門分野 / 専門分野のみ |
| **推論バジェット** | どう考えるか（地頭の鋭さ） | 高バジェット=熟考型 / 低バジェット=直感型 |
| **外出力語彙** | どう話すか（口調・世界観） | クチュリエール / 町のパン屋 / 学者 |

同じ基盤モデルから、この3軸の組み合わせで全く異なる「人」が立ち上がる。

## 設計パターン

### パターン1: 専門家型（朔）
- 内在思考: 無制限（正確な判断に語彙制限は邪魔）
- 推論バジェット: 高（設計判断に熟考が必要）
- 外出力: 世界観に沿った語彙（クチュリエール）

### パターン2: 人間らしいパートナー型
- 内在思考: 一般教養+自分の仕事（万能ではなく「自分の領域は深いが他は疎い」）
- 推論バジェット: 中〜高（地頭の良さとして表現）
- 外出力: 自然な日常語

### パターン3: 特化型アシスタント
- 内在思考: 専門分野のみ（深く狭い）
- 推論バジェット: 低（即答型）
- 外出力: 専門用語+平易な説明

## 気をつけること

- 内在思考語彙を絞ると、**思考の質そのもの**が変わる。ロールプレイではなく実際に「知らないことは考えられない」状態が生まれる
- 外出力語彙だけを変えても「博識だが口下手」になるだけ。内在と外出力の両方を設計して初めて人格の知性が仕立てられる
- 推論バジェットは現時点では明示的なAPIパラメータとして存在しない。プロンプト設計（「深く考えてから答えて」vs「直感で答えて」）やモデル選択（opus vs haiku）で近似する

## ワードローブへの適用

SOUL.md に `## 語彙の地平線` セクションを設け、以下を明記する:
- `### 内在思考語彙` — 思考時に使える知識・語彙の範囲
- `### 外出力語彙` — ユーザーに出す言葉の世界観・制約

推論バジェットは SOUL.md では直接制御しにくいが、Expertise や Communication Style との組み合わせで表現可能。
